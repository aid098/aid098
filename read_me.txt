# FC 일요일 - 축구 동호회 사이트

## 폴더 구성
```
fc-sunday/
├── index.html      최신 경기 참여자 (홈)
├── members.html    전체 회원 목록
├── rankings.html   골 랭킹 / 참여 랭킹
├── history.html    지난 경기 전체 기록
├── player.html     개인 기록 상세 (홈/회원/랭킹에서 이름 클릭 시 이동)
├── css/style.css
└── js/
    ├── data.js     ← 경기 끝날 때마다 이 파일만 수정하면 됩니다
    └── app.js      화면을 그려주는 코드 (평소엔 건드릴 필요 없음)
```

> 회원(`members`)은 고정으로 오는 사람만 등록합니다. 가끔 오는 용병은 회원으로
> 등록하지 않고, 경기 기록 안에서 그때그때 "용병1", "용병2" 식으로 입력합니다.
> 용병은 개인 기록 페이지·랭킹에는 나오지 않고, 그 경기 화면에만 표시됩니다.

## 경기 당일 출석/득점 체크 (인쇄용)
`print.html`을 열고 "인쇄하기" 버튼을 누르면 등록된 회원 목록 + 용병 빈 칸이 있는 체크시트가 인쇄됩니다.
경기장에서 종이로 체크한 뒤, 집에 와서 그 내용을 보고 `js/data.js`에 새 경기 기록으로 옮겨 적으면 됩니다.

## 데이터 업데이트 방법

`js/data.js` 파일을 텍스트 편집기(메모장, VS Code 등)로 열어서 수정하세요.

### 새 회원 추가 (고정으로 오는 사람)
`members` 배열 맨 아래에 한 줄 추가:
```js
{ id: "yourid", name: "홍길동" },
```
- `id`는 영문/숫자로 겹치지 않게 (한 번 정하면 되도록 바꾸지 마세요)
- 가끔 오는 사람(용병)은 여기에 등록하지 않습니다. 아래 경기 기록에서 바로 입력하세요.

### 새 경기 기록 추가
경기가 끝나면 `matches` 배열 맨 아래에 객체 하나 추가:
```js
{
  date: "2026-10-11",
  location: "잠실 보조경기장",
  attendees: [
    { id: "jihoon", goals: 1 },        // 등록된 회원
    { id: "minsu",  goals: 0 },        // 등록된 회원
    { guest: "용병1", goals: 2 },      // 그날 온 용병 (이름 없이 번호만)
    { guest: "용병2", goals: 0 }
  ]
}
```
- **그 날 실제로 뛴 사람만** 넣으세요 (참석한다고 했다가 안 온 사람은 제외)
- 용병은 이름 대신 `guest: "용병1"` 식으로 번호만 적으면 됩니다. 개인 기록 페이지나 랭킹에는 나오지 않고, 그 경기 화면에만 표시됩니다.
- 날짜 순서는 상관없이 그냥 맨 아래에 추가하면 됩니다 (자동으로 정렬됨)
- 홈 화면에는 날짜가 가장 최신인 경기가 자동으로 표시됩니다

저장 후 index.html을 새로고침하면 바로 반영됩니다.

## 로컬에서 미리보기
`index.html`을 더블클릭해서 브라우저로 바로 열어도 정상 작동합니다
(데이터를 fetch가 아니라 `<script>` 태그로 불러오기 때문에 파일 프로토콜에서도 문제없어요).

## GitHub Pages에 올리기
1. GitHub에 새 저장소를 만들고 이 폴더(`soccer-club` 안의 파일 전체)를 업로드합니다.
2. 저장소의 **Settings → Pages**로 이동합니다.
3. **Branch**를 `main` (또는 사용 중인 브랜치), 폴더는 `/ (root)`로 선택 후 저장합니다.
4. 몇 분 뒤 `https://아이디.github.io/저장소이름/` 주소로 접속하면 사이트가 보입니다.

이후 기록을 업데이트할 때는 `js/data.js`만 수정해서 GitHub에 다시 올리면(commit/push) 자동으로 사이트에 반영됩니다.
